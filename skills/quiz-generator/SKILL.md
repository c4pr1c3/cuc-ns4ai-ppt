# Quiz Generator (测试题生成器)

本技能用于根据课程课件（Markdown）和录音转写稿（Txt），自动生成包含单选、多选、判断题的测试题，并保存为纯文本文件。

## 输入资源

*   **课件**: 课程相关的 Markdown 文件（如 `slides/*.md`）。
*   **录音**: 课程录音转写文本（如 `recordings/YYYYMMDD/*.txt`）。

## 执行步骤

1.  **分析内容**:
    *   阅读并理解课件中的核心概念、命令、参数和原理。
    *   阅读录音转写稿，提取讲师强调的重点、补充的实战经验、以及提到的易错点。
    *   对比课件与录音，找出课件中未提及但录音中强调的知识点（“潜规则”或“实战坑点”）。

2.  **编制题目**:
    *   基于上述分析，编制以下数量的题目：
        *   **单选题**: 10 道
        *   **多选题**: 5 道
        *   **判断题**: 5 道
    *   题目内容应覆盖基础概念、命令使用、参数辨析、原理理解、实战场景判断等。
    *   **特别注意**: 包含讲师强调的易错点和实战经验（如 AI 幻觉、跨平台差异等）。

3.  **格式化输出**:
    *   严格遵循题目模版文件：`./templates/question-template.txt`。
    *   **模版关键点**:
        *   每道题题干后必须标注分值（如 `(6分)`，具体分值参考模版）。
        *   选项标记使用 `*`（未选中）和 `(*)`（选中/正确答案）。
        *   多选题正确选项使用 `[*]`。
        *   判断题正确选项使用 `<*>`。
        *   **答案解析**: `## 正确答案为 ...` 后**严禁**使用硬编码的字母（如 A、B、C），必须使用**正确选项的完整或简要文本描述**。这是因为在线考试系统会随机打乱选项顺序，硬编码字母会导致解析指向错误。
        *   包含 `&& 关键词` 的标签行。
    *   **重要约束**: 输出文件必须是**纯文本格式**，**严禁使用 Markdown 语法**（如 `**加粗**`、`code` 代码块等），以便导入在线测试系统。

4.  **保存文件**:
    *   将生成的题目写入 `quiz/YYYYMMDD.md` 文件（文件名使用当前日期）。
    *   确保文件内容符合模版要求且无 Markdown 格式标记。

## 示例引用

*   模版路径: `./templates/question-template.txt`
